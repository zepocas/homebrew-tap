# zepocas/homebrew-tap

Homebrew casks for [zepocas](https://github.com/zepocas) projects.

```sh
brew install --cask zepocas/tap/komorebi-menubar
```

| Cask | Project |
|---|---|
| `komorebi-menubar` | [Komorebi Menubar](https://github.com/zepocas/komorebi-menubar), a menu bar workspace indicator for komorebi for Mac |

Casks are updated with `scripts/bump-cask.sh` in each project's repo.
